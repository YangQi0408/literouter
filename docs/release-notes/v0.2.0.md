# v0.2.0 — Personal Local AI Aggregator

## Highlights

- **Single-user local gateway**: Every user runs an independent local instance with one `server.api_key` protecting both model and management APIs. Client accounts, per-client keys, permission groups, quota ledgers, and daily budgets are not part of this release.
- **Built-in Web Console**: The React/Vite console remains embedded in the server at `/ui/`. It provides telemetry, provider and route editing, health probing, request logs, and secure configuration editing.
- **Provider aggregation**: Route logical models across multiple providers with model aliases, retry budgets, header-gated streaming failover, circuit breaking, relay concurrency and rate limits, session affinity, and an optional local response cache.
- **Protocol coverage**: OpenAI, Anthropic, Gemini, OpenAI Responses, Azure OpenAI, Vertex AI, AWS Bedrock, and Ollama protocol paths are supported with passthrough or bidirectional conversion as appropriate.
- **Operations**: Cross-platform GitHub Releases, checksum files, a Linux installer, Docker/Compose images, and a hardened systemd unit are available for personal deployments.

## Upgrade Notes

- The current configuration schema is `3`. Configuration fields from the former API-distribution and desktop-GUI surfaces are migrated away rather than silently written back.
- Store provider and server secrets as environment-variable placeholders where possible. The configuration writer preserves those placeholders and never writes resolved secrets back to disk.

## Installation

Download the archive for Linux x86_64, macOS arm64, or Windows x86_64 from the GitHub Release, verify its `.sha256` file, and run `literouter serve`. Linux users can also install the latest binary with:

```bash
curl -fsSL https://raw.githubusercontent.com/YangQi0408/literouter/main/scripts/install.sh | bash
```

Then open `http://127.0.0.1:8787/ui/` to use the built-in Web Console.
