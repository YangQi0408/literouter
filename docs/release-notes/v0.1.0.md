# v0.1.0 — Initial Release (内置 Web 控制台与多协议代理)

## 🚀 新特性

- **高性能多协议聚合**：对外提供统一 OpenAI 兼容端点（`http://127.0.0.1:8787/v1`），支持 OpenAI、Anthropic Claude、Google Gemini 协议双向无缝转换。
- **现代化内置 Web 控制台**：基于 React 19 + TypeScript + Vite + Tailwind CSS v4 + shadcn/ui，编译期通过 C++23 `#embed` 内嵌至二进制，随服务自带，支持概览看板、中转站健康状态矩阵、一键存活探测、路由优先级拖拽调序、多维日志流与在线配置保存。
- **响应头闸门 (Header Gate)**：独创流式安全机制，连接超时、429 或 5xx 无感故障转移；首包响应头下发后立即锁定连接，彻底杜绝回答流交叉拼接。
- **密钥安全持久化**：支持环境变量占位符引用（`${VAR}`），仅在请求瞬间内存解析，配置文件保存时绝不写回明文。
- **三前端协同**：提供原生 CLI 命令行（`literouter`）、内置 Web 控制台（`/ui`）以及基于 OpenGL 的桌面 GUI（`literouter-gui`）。

## 📦 安装与使用

下载对应平台的压缩包并解压：
- **Linux (x86_64)**: `literouter-v0.1.0-linux-x86_64.tar.gz`
- **macOS (Apple Silicon)**: `literouter-v0.1.0-macos-arm64.tar.gz`
- **Windows (x86_64)**: `literouter-v0.1.0-windows-x86_64.zip`

启动前台代理服务：
```bash
./literouter serve
```
然后在浏览器访问控制台：`http://127.0.0.1:8787/ui/`
