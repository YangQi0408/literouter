# 桌面控制台 (GUI) 使用指南

> 在无头服务器/容器里运行？用内置的 [Web 控制台](protocols-api.md#内置-web-控制台-web-console)，浏览器打开 `/ui` 即可，无需图形环境。

`literouter-gui` 是专为开发者打造的原生 OpenGL 桌面控制台前端。它基于声明式轻量 GUI 框架构建，拥有极低资源开销，提供实时遥测、中转站健康矩阵、路由可视化调整与日志审查功能。

## 启动与运行

在工程根目录执行以下命令即可启动桌面控制台：

```bash
mcpp run -p gui
```

> [!NOTE]
> 在 GUI 模式下，底层代理服务（`literouter.core`）与图形界面运行在同一个进程内部。打开控制台后，点击右上角【启动代理】开始监听配置的端口（默认 `8787`），无需额外开启命令行终端。

## 六大核心面板

```text
┌─────────────────────────────────────────────────────────────────────────────┐
│ LR  literouter  │  概览  中转站  路由  日志  设置  │ [-] 100% [+] [中/EN] ● 运行中 │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  [ 总请求数 ]     [ 成功率 ]     [ 处理中 ]     [ 平均延迟 ]     [ Token 总数 ] │
│     1,248          99.2%           0            412 ms          3.8M        │
│                                                                             │
│  中转站健康矩阵 (Relays)                                                    │
│  ┌─────────────────────────┐  ┌─────────────────────────┐                   │
│  │ OpenAI 官方      ● 正常 │  │ DeepSeek 备用   ● 降级  │                   │
│  │ priority 10 · 1.1k ok   │  │ priority 20 · 128 ok    │                   │
│  └─────────────────────────┘  └─────────────────────────┘                   │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

### 1. 概览面板 (Overview)
- **全局指标磁贴**：实时展示服务启动以来的总请求数、成功率、当前在途处理中并发数、平均往返延迟（RTT）、累计 Token 用量、下发流量与**应答缓存命中数**；
- **流量趋势**：按配置的**时间桶宽度与桶数量**（设置面板的「性能与指标」卡片）绘制请求数柱图，不再写死 24 个整点小时——例如桶宽 60 秒 × 30 个桶就是「最近 30 分钟」。以最高桶为比例绘制，无请求的桶保留空位，包含失败请求的桶用黄色标记。悬停可查看本地时间、请求成功/失败数、Token、下发流量与估算费用。无流量时显示空状态，开启遥测持久化后可继续查看重启前的记录；
- **中转站健康矩阵**：以卡片网格直观展现每个上游站点的熔断状态（正常/健康绿色、半开黄色、熔断冷却红色）、连续失败计数与成功吞吐；
- **活动告警栏**：一旦有中转站触发熔断或网络异常，顶端立即弹出告警条，点击可一键查看原因或重置状态。

### 2. 中转站面板 (Providers)
- **节点生命周期**：支持一键启用/禁用任意上游中转站，配置优先级（Priority）、权重（Weight）以及超时时间；
- **双窗格编辑器**：点击【编辑】打开编辑器，顶部分段控件在**「中转站」**与**「协议设置与限流」**两个窗格间切换。之所以拆成两屏而不是一屏长表单：编辑器面板高度会被对话框组件按屏幕高度裁剪，单屏塞下全部字段会把【保存】按钮挤出可见区域；两个窗格各自完整可见，都不需要滚动；
- **协议与凭据（第二个窗格）**：选择出口协议（`openai` / `azure` / `anthropic` / `gemini` / `vertex` / `bedrock` / `ollama` / `responses`），并按所选协议**条件显示**对应字段——Azure 的 `api-version`、Vertex 的项目 ID / 区域 / 服务账号密钥文件、Bedrock 的区域 / Access Key ID / Secret Access Key / 会话令牌，以及 Ollama 只需填写基址。密钥字段支持 `${VAR}` 环境变量引用，**引用在配置文件中保持为引用，只在为请求签名的瞬间才解析**；
- **中转站侧限流**：在同一窗格设置「并发请求数」与「每分钟请求数」（0 表示不限）。到达上限的中转站会被**跳过而不是判为失败**——它不会触发熔断，请求会交给候选链里的下一个站点；
- **上游连通性测试**：点击【测试】按钮即时发起 TCP/TLS 握手与 API 存活测试，实时反馈网络延迟；
- **模型自动探测与一键同步**：点击【探测模型】，系统会自动向上游拉取支持的所有可用物理模型列表，并支持一键将探测到的模型合并至配置文件中。

### 3. 路由面板 (Routes)
- **可视化候选链**：以节点流程图的形式展现每个逻辑模型的故障转移兜底次序（主用站点 -> 备用站点 A -> 备用站点 B）；
- **物理模型重命名**：直观配置各个节点上的物理模型映射，支持拖拽或方向箭头快捷调序。

### 4. 日志面板 (Logs)
- **高性能虚拟化列表**：支撑数百条请求日志的高帧率流畅滚动；
- **多维筛选**：支持按日志等级（全部 / 信息 / 警告 / 错误）快速过滤；
- **即时全文搜索**：支持对请求路径、模型名称、错误信息进行毫秒级高亮检索；
- **详情侧拉框**：点击任意日志条目即可展开完整的请求元数据、耗时细分、上游响应状态以及截断的报文摘要。

### 5. 设置面板 (Settings)
- **服务端参数配置**：直观修改监听地址、监听端口与管理员密钥；
- **熔断策略调节**：图形化滑动调节熔断连续失败阈值与冷却时间；
- **遥测持久化开关**：选择计数器、中转站统计与请求日志是否写入状态目录，重启后继续累计；
- **性能与指标卡片**：集中管理控制台保留什么、指标发往何处——
  - **趋势时间桶宽度（秒）**与**保留的时间桶数量**：共同决定概览页趋势图的时间跨度（宽度 × 数量）；
  - **应答缓存有效期（秒）**与**缓存条目上限**：前者为 0 表示关闭缓存（**流式响应永不缓存**），后者限制 LRU 淘汰前的条目数；
  - **OTLP 指标端点**：留空表示不导出；填写后指标按固定周期推送到 `{endpoint}/v1/metrics`；
- **热重载与安全保存**：支持一键将内存修改安全落盘（严格保留环境变量密钥），或从磁盘重新载入最新文件；
- **接入示例代码生成**：提供预设好的 `curl`、OpenAI Python SDK、LangChain 配置示例代码，支持一键复制。

---

### 6. 客户端面板 (Clients)
- **可选分发能力**：个人自用无需账户；创建首个客户端前先在设置中填写管理员密钥。账户密钥只能调用模型接口。
- **账户编辑器**：支持名称、启停、允许的模型和中转站组，以及每分钟请求数、并发、每日请求/Token 配额、每次请求预留 Token 与**每日预算（美元）**。允许列表留空表示不限，配额为 0 表示不限；
- **每日预算**：按**金额**而不是 Token 数封顶，因此不必猜上游的计价方式。预算在**请求到达时**校验，到达上限后新请求返回 `429`；但已经在途的请求仍会跑完（它的实际花费此时才由上游结算），因此当日累计可能略微超过上限。卡片上以「已花 / 上限」显示；
- **多密钥管理**：添加、替换、启用、禁用和删除账户内的密钥；已存值保持隐藏，替换值留空会保留原密钥或环境变量引用。密钥修改先进入草稿，【保存客户端】后生效，【取消】放弃草稿。验证或磁盘写入失败时保留草稿，并保持运行中的配置不变。
- **实时用量**：展示请求成败、处理中请求、Token 配额与预留量、估算费用，与 API 使用同一配额账本。每日配额于 UTC 零点重置；上游缺失用量时仍保留预留扣费。清空图表统计或关闭遥测不会重置配额。
- **中转站组**：在中转站编辑器填写以逗号分隔的组名，再于客户端中限制允许的组。日志详情显示客户端与密钥 ID，日志搜索也支持这两个字段。

## 与 Web 控制台的功能对齐

桌面控制台（`literouter-gui`）与内置 Web 控制台（`/ui`）是两条独立前端，但提供同一套管理能力。本节的对应关系是**逐项核对过**的，不是大致相当。

### 页面一一对应

| 桌面控制台 | Web 控制台 | 职责 |
|---|---|---|
| 概览 | Overview | 指标磁贴、流量趋势、中转站健康矩阵 |
| 中转站 | Providers | 上游节点增删改、探测、连通性测试 |
| 路由 | Routes | 候选链与模型映射 |
| 日志 | Logs | 请求日志筛选、搜索与详情 |
| 设置 | Settings | 服务端参数、熔断策略、性能与指标、示例代码 |
| 客户端 | Clients | 账户、密钥、配额与每日预算 |

### 字段一一对应

新增的配置字段在两条前端上**全部可编辑**（已逐字段 grep 核对）：`response_cache_ttl_sec`、`response_cache_max_entries`、`traffic_bucket_sec`、`traffic_bucket_count`、`otlp_endpoint`、`max_concurrent`、`requests_per_minute`、`budget_usd_per_day`，以及协议相关的 `api_version`、`region`、`project`、`credentials_file`、`aws_access_key`、`aws_session_token`。

### 刻意不对齐的部分

以下是**设计取舍而非遗漏**，不要当成待补的缺口：

- **`bench` 与 `replay` 只在 CLI**。它们会真的向上游发请求、真的花钱，属于命令行的一次性诊断工具，不适合放进常驻控制台；
- **Web 控制台有配置导出/导入，桌面控制台没有**。桌面版直接编辑本机配置文件，「导出」没有意义；Web 版常跑在远端或容器里，才需要把配置搬进搬出；
- **Prometheus 指标（`/__literouter/metrics`）不做图形化**。它是给抓取器读的文本端点，两条前端都只展示同一份快照的友好视图；
- **日志等级/类型筛选的控件形态不同**，但可用筛选项集合一致。

### 文案字典是两套

CLI 与 GUI 共用 C++ 侧的 `literouter::i18n::tr()`（中文字典在 `core/src/lr_i18n.cpp` 的 `kZhTranslations`）；Web 控制台用完全独立的 `web/src/lib/i18n.tsx`（`en` / `zh` 两个 map）。**新增任何用户可见文案，必须补对应的一侧**；C++ 侧漏了会静默回退英文（见 `AGENTS.md` 规则 9）。

## 多语言切换 (i18n)

控制台内置完善的中英双语本地化引擎：

- **图形界面一键切换**：在顶栏右上侧点击 `[中/EN]` 按钮，即可瞬间切换全界面的文字语言；
- **语言模式**：
  - `简体中文`
  - `English`
  - `跟随系统 (Auto)`：启动时自动读取操作系统语言环境变量（`LANG`, `LC_ALL`, 或 Windows 区域设置）；
- **环境变量锁定**：
  ```bash
  LITEROUTER_LANG=zh mcpp run -p gui
  ```

## 界面矢量自由缩放 (UI Scale)

为了适配从 1080P 到 4K 高分屏的各种显示设备，GUI 支持全矢量动态平滑缩放：

- **缩放档位**：`80%`、`90%`、`100%`、`110%`、`125%`、`150%`；
- **顶栏步进控件**：点击顶栏的 `[-]` 和 `[+]` 按钮即时微调；
- **全局快捷键**：
  - `Ctrl` + `+`（或小键盘 `+`）：放大界面
  - `Ctrl` + `-`（或小键盘 `-`）：缩小界面
  - `Ctrl` + `0`（或小键盘 `0`）：恢复为 100% 原始大小
- **环境变量预设**：
  ```bash
  LITEROUTER_UI_SCALE=1.25 mcpp run -p gui
  ```

## 高清中文字体自适应

针对部分 Linux 桌面中文显示模糊或乱码的问题，启动时会自动扫描系统清晰字体，并依序智能加载：

1. **更纱黑体 (Sarasa Gothic)**：基于思源黑体与 Iosevka 融合打磨，中英文等宽且极具清晰度；
2. **文泉驿正黑 (WenQuanYi Zen Hei)**：Linux 平台经典高质量中文开源字体；
3. **Noto Sans CJK**（思源黑体系列）；
4. **微软雅黑** (`msyh.ttc`，Windows) / **苹方** (`PingFang.ttc`，macOS)。

若需指定自定义字体文件，可通过环境变量指定：
```bash
LITEROUTER_GUI_FONT="/usr/share/fonts/opentype/noto/NotoSansCJK-Regular.ttc" mcpp run -p gui
```

## 无头自动化冒烟测试

在持续集成（CI）或代码重构时，无需人工开启显示器即可验证 GUI 的完整渲染稳定性：

```bash
LITEROUTER_GUI_SMOKE=1 mcpp run -p gui
```

该命令会启动图形引擎，自动模拟切换全部 6 大功能页面，各渲染 150 帧以验证内存安全与组件布局，无任何渲染崩溃后干净退出。
